# 📱 Realtime Messenger App

A professional mobile messaging application featuring **real-time chat**, **user authentication**, and **secure communication**.

## ✨ Features

- 🔐 Secure User Authentication (Email, Google, Phone)
- 💬 Real-time Messaging with Typing Indicators
- 👥 Group Chats and Channels
- 🔒 End-to-End Encryption
- 📎 File Sharing & Media Support
- 🔔 Push Notifications
- 🌙 Dark/Light Theme Support

## 🛠 Tech Stack

- **Frontend**: Flutter or React Native
- **Backend**: Firebase / Supabase
- **Real-time**: Firestore / WebSockets
- **Authentication**: Firebase Auth
- **Storage**: Cloud Storage

## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/abdelazizzeslam/realtime-messenger-app.git
cd realtime-messenger-app

# Install dependencies
flutter pub get  # or npm install

# Configure environment variables
cp .env.example .env

# Run the app
flutter run
```
